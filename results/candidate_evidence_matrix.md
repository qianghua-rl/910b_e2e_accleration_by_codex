The 2% screen is an end-to-end target; local kernel or profiler time is an upper-bound input only, not a measured gain. “Possible removable cost” records a mechanism hypothesis, not an assumption that the cost is removable.

## Gate

Only routes with both a credible >=2% end-to-end upper bound and a cheap falsifier may enter implementation. Under the current evidence, no new GDN conversion experiment qualifies. The GDN conversion branch is therefore paused pending finer module-level trace evidence; this is an evidence-based stop, not a claim that all GDN optimization is impossible.
